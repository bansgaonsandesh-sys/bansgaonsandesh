📝 3-STEP MIGRATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: EXPORT 📥
─────────────────
Get OLD Supabase DB URL:
Dashboard > Settings > Database > Connection string

export SUPABASE_DB_URL="postgresql://postgres:PASSWORD@db.OLD.supabase.co:5432/postgres"
./export_supabase_db.sh

⏱️ Takes: 2-3 minutes


STEP 2: CREATE NEW PROJECT 🆕
──────────────────────────────
1. Go to supabase.com/dashboard
2. Click "New Project"
3. SAVE these:
   • Project URL: https://XXX.supabase.co
   • Anon key: eyJhbGc...
   • Service key: eyJhbGc...
   • DB password: (your choice)

⏱️ Takes: 2 minutes


STEP 3: IMPORT 📤
─────────────────
Get NEW Supabase DB URL:
Dashboard > Settings > Database > Connection string

export NEW_SUPABASE_DB_URL="postgresql://postgres:NEW_PASSWORD@db.NEW.supabase.co:5432/postgres"
./import_to_new_supabase.sh

Type: yes

⏱️ Takes: 3-5 minutes
